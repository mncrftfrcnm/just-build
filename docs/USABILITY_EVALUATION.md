## Process and regression findings

The focused independent review found and verified fixes for a missing-listener bypass: a failed novice round could formerly be replaced before an advocate addressed its difficulties. Every retained earlier round now needs an advocate before another novice can be recorded. Recheck can recover a latest orphan without restoring stale approval. Tests also cover a source edit after Quality completes but before Polish starts; recovery now reopens the necessary approvals instead of stranding the run.

Review also clarified that evidence JSON belongs in the ignored state directory or outside the product source. Creating it beside application source changes the fingerprint; source exclusions were kept intact. Twenty new gate regressions and two context-isolation regressions bring each host suite from 151 to 173 tests. Both complete suites passed with no skips on Windows/Python 3.13.5. Context packets prevent the simulated first user from seeing test answers, reviewer verdicts or private implementation notes; project content remains untrusted data.

The process limits repairs to three novice rounds, requires current-source approval and preserves frozen acceptance. It cannot prove an agent told the truth or two declared identities are independent. First-user simulations do not establish accessibility, human time-on-task, customer demand or successful browser/mobile delivery. Actual Claude Code and hosted CI remain unobserved, as disclosed in the main evaluation.
